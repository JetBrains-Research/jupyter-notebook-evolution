    * 'no change': The two pieces of code in the transition are identical. There is no change. 
    * 'explore variable': Code is added or edited to (further) explore the content or shape of a variable without changing the state of the code. Operations may be applied to the content of a variable, but then the result is only displayed or printed, not assigned to a variable. 
    * 'fix': Code is edited or extended to fix a syntactic error. 
    * 'debug': Code is changed and/or added to 1) identify the source of a problem that leads to functional incorrectness or 2) to find a solution to the problem or both 1) and 2).
    * 'edit code': Code is changed to adjust certain things and possibly obtain better results. This kind of change changes the state of code. In other words, there is a variable assignment involved in or affected by the code change. Please note that editing code to explore a variable differently should not be classified as 'edit code' but instead it should be classified as a case of 'explore variable'.
    * 'clean code': Code was deleted. 
    * 'visualize data': A data visualization (e.g., a plot) is created or edited."
    * 'extend code': Code that is extended with new partial or complete pieces of code to drive the development further. This kind of change changes the state of code. Please note that adding code to explore a variable further should not be classified as 'extend code' but instead it should be classified as a case of 'explore variable'. Analogously, adding code to create or refine a visualization should not be classified as 'extend code' but instead it should be classified as a case of 'visualize data'.
    * 'improve readability': Code was changed to improve the formatting of the code and make it easier for developers to read and understand it.
    * 'comment': Comment code. 
    * 'uncomment': Uncomment code that was previously commented. 
    If you think there is a goal that we did not list, please give it a name and use 
    it consistently every time you encounter an instance of that goal.
    You need to return:
      - The name of the goal
      - An explanation about the goal name you picked for this classification problem
